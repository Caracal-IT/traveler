# Agent Skills

This section provides an overview of the skills available for Copilot agents, including their purpose, usage,   
and configuration options. Agents can be customized to perform specific tasks by selecting and configuring the   
appropriate skills.

## Anatomy of a Skill

[Agent Skills](https://agentskills.io/home)

A skill is a modular component that defines a specific capability or function for an agent.   
Each skill has the following attributes:  
- **Name**: A unique identifier for the skill.
- **Description**: A brief explanation of what the skill does.
- **Functionality**: The specific task or action the skill performs.
- **Configuration**: Any parameters or settings required to use the skill effectively.
- **Dependencies**: Other skills or external resources the skill may rely on.
- **Error Handling**: How the skill handles unexpected situations or errors.
- **Performance**: Performance characteristics and potential bottlenecks.
- **Security**: Any security considerations or best practices for using the skill.
- **Documentation**: Detailed instructions and examples for using the skill.

### Front matter

The front matter of a skill is a YAML block that contains metadata about the skill. It includes the following fields:
- `name`: The name of the skill.
- `description`: A brief description of what the skill does.
- `parameters`: A list of parameters that the skill accepts, including their names, types, and descriptions.
- `dependencies`: A list of other skills that this skill depends on, if any.
- `error_handling`: A description of how the skill handles errors, if applicable.
- `performance`: A description of the performance characteristics of the skill, if applicable.
- `security`: A description of any security considerations for using the skill, if applicable.
- `documentation`: A link to detailed documentation for the skill, if applicable.

### Body

The body of a skill is where the actual skill logic is defined. This can include code snippets, examples, and   
detailed instructions for using the skill. The body should provide clear and concise information to help users   
understand how to use the skill effectively. 100 words or less is recommended.
