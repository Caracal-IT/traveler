# Agents

## Simple Agent

```bash
copilot agent --name "Simple Agent" --description "A simple agent that responds to user input." --prompt "You are a helpful assistant. Respond to the user's input in a concise manner."
```

## Advanced Agent

```bash
copilot agent --name "Advanced Agent" --description "An advanced agent that can perform complex tasks." --prompt "You are an expert assistant. Respond to the user's input in a detailed manner." --model "gpt-4"
```

## Customizable Agent

```bash
copilot agent --name "Customizable Agent" --description "A customizable agent that can be configured to suit your needs." --prompt "You are a versatile assistant. Respond to the user's input in a manner that suits their needs." --model "gpt-3.5-turbo" --temperature 0.7 --max_tokens 1024
```
